# ShopKart - Full-Stack E-Commerce Application

A modern full-stack E-Commerce platform inspired by Amazon and Flipkart, built using React, Node.js, Express.js, MongoDB, Redux Toolkit, and Tailwind CSS.

## Features
- User Authentication with JWT & bcrypt
- Product Search, Filters, Sorting & Pagination
- Shopping Cart & Checkout System
- Wishlist & Recently Viewed Products
- Product Reviews & Ratings
- Responsive Modern UI/UX
- Admin Dashboard for Products, Users & Orders
- REST API Integration
- MongoDB Database Integration
- Dark/Light Mode Support

## Tech Stack
### Frontend
- React.js
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Deployment
- Frontend: Render
- Backend: Render
- Database: MongoDB Atlas
